# midterm_exam 폴더의 규칙

과제 「시간대로 나누어 다시 보기」(과제 1~8)를 이 폴더 안에서 한다.
이 폴더에서는 상위 폴더의 AGENTS.md 대신 이 파일을 따른다.

## 폴더 구성
- 노트북과 스크립트는 이 폴더 바로 아래에 `01_long_format.ipynb`처럼 번호를 붙여 만든다.
- 정리한 데이터는 `midterm_exam/data/`, 그림은 `midterm_exam/output/figures/`에 저장한다. 폴더가 없으면 만든다.
- 그 밖에 하위 폴더가 필요하면 먼저 이유를 말하고 만든다.
- 이 폴더 바로 아래 노트북에서 상위 자료는 `../dataset/...`로 읽는다. 하위 폴더에서 읽으면 `../../dataset/...`로 바꾼다.

## 자료
- 상위 폴더의 `dataset/raw/`와 `dataset/working/`은 읽기만 한다. 수정하거나 지우지 않는다.
- 시작 자료는 `../dataset/working/subway_clean.csv`(UTF-8)와 `../dataset/raw/seoul-temp-raining-2025.csv`(EUC-KR, 4장 방식으로 weather를 다시 만든다)이다.
- 긴 형식 표(약 400만 행)는 파일로 저장하지 않고 노트북 안에서 다시 만든다.
- 공휴일 목록은 직접 찾아 `data/`에 저장하고, 출처를 노트북에 적는다.

## 언어와 패키지
- R과 Python 중 하나로 한다. R은 tidyverse, Python은 pandas와 matplotlib만 쓴다.
- Python은 상위 폴더의 uv 가상환경(.venv, Python 3.12)을 쓴다. 패키지는 uv add 로만 설치하고 pip install 은 쓰지 않는다.
- 다른 패키지가 필요하면 먼저 이유를 말하고 허락을 받은 뒤 설치한다.

## 그림
- R은 ggplot2로 그리고, 한글 글꼴은 showtext의 font_add_google()로 Noto Sans KR을 등록해 쓴다. ggsave()로 PNG를 저장한다.
- Python은 matplotlib으로 그리고, 한글 글꼴은 Windows의 Malgun Gothic을 쓴다. savefig()로 PNG를 저장한다.
- 그림 제목에는 그림 종류가 아니라 주장을 적는다(6장 6.3).

## 진행 방식
- 시킨 것만 바꾼다. 시키지 않은 구성요소(테마, 색, 축 범위 등)는 기본값이나 지금 상태 그대로 둔다.
- 데이터를 바꾸는 작업 전후에는 행 수를 출력해서 보여준다. 조인 뒤에는 결측 개수도 출력한다.
- 코드를 고칠 때는 무엇을 왜 바꿨는지 한 줄로 설명한다.
- 확실하지 않은 함수나 인수는 지어내지 말고 확실하지 않다고 말한다.
- 노트북은 제출 전에 처음부터 끝까지 오류 없이 실행되는지 확인한다(과제 8).
- 전체 작업이 끝나면 상위 폴더의 README.md에 이 폴더의 작업 내용을 적는다.

## 다음 사항은 사용자의 요청이 있을 경우에만 따른다.
- A. 현재까지 작업을 누적하여 일자별+작업별로 `handsoff.md` 파일을 통해 관리한다.
- B. 각 작업 단계별로 사용자의 승인여부를 확인한다. 승인이 있을 경우에만 다음 단계 작업을 실시한다.
- C. 사용자가 지시한 작업을 이행하기 전에, 어떤 방식으로 작업을 할 것인지 구체적으로 설명 후, 사용자의 컨펌을 받은 후 작업 실시한다.
